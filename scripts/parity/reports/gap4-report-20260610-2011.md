## 3) 💡 הצעות קוד/סכמה (לא יושמו — לסשן הדיפלוי המרוכז)

### הצעה A (מומלצת): תיוג סדרות + TopicPage מעורב
1. **סכמה:** `CREATE TABLE series_topics (series_id uuid REFERENCES series(id), topic_id uuid REFERENCES topics(id), PRIMARY KEY (series_id, topic_id));` + RLS read-public כמו lesson_topics.
2. **קוד `TopicPage.tsx`:** שאילתה שנייה ל-series_topics; להציג כרטיסי-סדרה (כמו דף-קטגוריה) מעל כרטיסי-השיעורים. סינון `audience_tags ∌ teachers` גם כאן (כלל 3!).
3. **קוד `useTopicsSidebar.ts`:** count = lessons + series (יישור לספירות הישן).
4. **דאטה (מוכן להרצה אחרי הקוד):** יצירת 2 הנושאים + ~84 שורות series_topics — רשימת ההתאמות המלאה (סדרה→נושא, כולל ה-5 התת-מאוכלסים) ניתנת לחילוץ מ-`gap4-yoav-split-20260610.json` (series_shaped) + `gap4-oldsite-subjects-fresh-20260610.json`. SQL ליצירת הנושאים:
```sql
INSERT INTO topics (id, name, slug, parent_id, sort_order) VALUES
 (gen_random_uuid(), 'תנ"ך מוקלט', 'theme-תנ-ך-מוקלט', '13ca4b52-c317-4bbc-8847-84ecc9e3691b', 0),
 (gen_random_uuid(), 'לימוד בקצב של פרק לשיעור', 'theme-לימוד-בקצב-של-פרק-לשיעור', '13ca4b52-c317-4bbc-8847-84ecc9e3691b', 0);
```
**אסור להריץ לפני שהקוד תומך** — אחרת 2 נושאי-0 בתחתית הסיידבר (נראה שבור).

### הצעה B (דאטה-בלבד, לא מומלצת): קישור כל שיעורי-הסדרות
1,632 קישורים; דורשת לפחות העלאת `.limit(500)` + pagination ב-TopicPage. נדחתה מהסיבות בסעיף 2.

### תיקוני קוד נלווים (בלי קשר להחלטה):
- `TopicPage.tsx`: ה-`.limit(500)` כבר היום מסוכן ל"ימי העיון בתנ"ך" (284 ועולה) — להוסיף pagination או להעלות.
- display-dedup לפי כותרת+רב ב-TopicPage (אם לא נכלל כבר בקוד הממתין) — 76 הקישורים ששמרתי בכוונה יציגו כרטיס כפול עד שסינון-המורים ייפרס; אחרי הדיפלוי הסינון מעלים את עותק-המורים והכפילות נעלמת.
