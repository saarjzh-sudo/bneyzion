## Normalization (all comparisons)
`normalize_he`: NFC → strip niqqud (U+0591–U+05C7) → **remove** quote-family chars (״ " ' ׳ \`) so that
`ט"ו == טו` → separator-family (| – — - _ , : ; ! ? ( ) [ ] { } < > . /) → space → collapse whitespace → lowercase.
Rabbi keys additionally drop honorifics (הרב/ד"ר/זצ"ל/שליט"א…) and are token-sorted.
Media URLs: percent-decode, `+`→space, NFC, strip host (incl. the `/bneyzion/` S3 bucket prefix), casefold →
compared by full path (gold) then basename.
Fuzzy = fuzzywuzzy-style token_set_ratio **guarded** by: chapter-signature intersection (tokens after פרק/פרקים —
blocks פרק ט ↔ פרק א), no single-letter token diff outside chapter refs (blocks שמואל א ↔ שמואל ב), no book-name
in the token diff (blocks ספר במדבר… ↔ ספר דברים…), no strict token-subset with >1 extra token (blocks
פילגש בגבעה ↔ "איך הגיעו ישראל לשפל של פילגש בגבעה"). Skeleton key (drop ו/י after first char per token)
catches ktiv male/haser (קרח == קורח).

## tree_map.json
`{_meta:{stats}, nodes:[…]}` — one entry per old nav node: **894 sidebar + 109 teachers by_book = 1,003**.

Entry: `{source: 'sidebar'|'teachers_by_book', old_url, old_url_norm, old_title, depth, order_index,
parent_old_url, node_kind, matched_series_id|null, matched_title, method, score, candidates[]}`

- `node_kind`: `category` (depth-1) | `book` (depth-2 under תורה/נביאים/כתובים) | `collection` |
  `event_series` (under ימי עיון) | `alias` ("כל השיעורים ב…"/"כל התכנים ב…"/"כל הפטרות…" → mapped to the same
  target as their book/section) | `external_link` | `empty` (leaf whose old listing page has 0 items).
- `method`: `exact_in_parent` (1.0) → `exact_in_subtree` (0.97) → `exact_global_unique` (0.95) →
  `exact_global_picked` → `fuzzy_in_parent` (token-set ≥0.85, guarded) → `skeleton_in_parent` (0.88) →
  `containment_in_parent` (0.86, length-ratio ≥0.5 + chapter-guarded) → `alias_of_parent` → `unmatched`.
- Deterministic tiebreak: direct-child-of-mapped-parent → in-subtree → audience fit (teachers vs public) →
  live status → **numeric lesson_count** (a 45-lesson series beats its 5-lesson duplicate — e.g. the two
  `פרשת קורח | טז-יח` rows under במדבר) → uuid. No strict winner ⇒ `matched=null` + `candidates[]`.

## item_match.json
`{_meta, listings:{url→page}, rabbi_pages:{rabbi_name→page}, topic_pages:{topic_name→page}, teachers:{key→page}}`
(teachers keys: `content_type::<name>`, `creator::<name>`, `by_book::<book>[::<sub_series>]`).

Page: `{url, h1, mapped_series_id|null, mapping_method, n_items, n_matched, items:[…], sub_series_match:[…],
new_extras:[…]}` + per-source extras (`mapped_rabbi_id`, `mapped_topic_id`, `expected_count_old`,
`sidebar_count_old`, `redirected_to`).

Item: `{idx, title, rabbi, type, matched_lesson_id|null, method, score, candidates[]? (when ambiguous/dup)}`.
`sub_series_match`: series-type rows (`סדרה`/`series`) matched against series like tree nodes.
`new_extras`: lesson ids whose `series_id` == the page's mapped series (audience-appropriate) but matched no
old item on that page. For rabbi/topic pages: unmatched lessons of the mapped rabbi/topic (informational —
old rav pages itemize only their table rows, 719 of ~7.5K effective).

Match keys in priority order (method names):
1. `media_path` (1.0 gold — old attachment/audio/video path == lessons.legacy_attachment_url/audio_url/
   video_url/attachment_url/additional_attachments path) → `media_basename` (0.98).
2. (same index covers audio/video URLs.)
3. `title_rabbi` (0.96) — exact normalized title + rabbi.
4. `title_only` / `title_rabbi_oneside` (0.9) — exact title, rabbi missing on one side.
5. `fuzzy_title` (≥0.92, guarded, same rabbi required).
- `*_dup` = several DB rows identical on (title, rabbi) — the night-session COPY duplicates; deterministic
  pick preferring the page's mapped series (display-dedup hides the rest in the UI).
- `*_after_media_amb` = a shared media file (booklet PDF etc.) matched several lessons; title keys decided.
- `ambiguous_*` = matched=null + candidates[] — no safe winner. Only **48** items remain ambiguous overall.
- Disambiguation order: exact-title equality → page's mapped series → its subtree → rabbi equality →
  audience fit → published → uuid; strict winner required.
